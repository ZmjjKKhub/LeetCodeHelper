{# The outcome buttons *are* the submit action: open -> (提交次数/模板) -> outcome is the whole flow (two clicks), so picking an outcome and saving must collapse into one click rather than staying two separate steps. DOM order: this fieldset comes *last* among interactive controls, on purpose -- 提交次数 and 用了哪个模板 must both be reachable before a click can submit the form, which is only guaranteed if they appear earlier in the DOM (tab order and "click reaches them" both follow DOM order here; there is no CSS order: override). This is a Jinja comment (stripped at render time), not an HTML comment, on purpose: an HTML comment here would be sent to the client and would literally contain text this form must not show, breaking any test/UX check for its absence. #}
